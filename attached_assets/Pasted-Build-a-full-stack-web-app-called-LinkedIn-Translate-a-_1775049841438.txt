Build a full-stack web app called "LinkedIn Translate" — a translator that 
converts plain, honest English into exaggerated LinkedIn corporate-speak.

Example:
Input: "I took a massive dump"
Output: "I just successfully completed a high-volume output optimization session. 
Grateful for the process. Making room for the next big challenge. 
The journey is never linear. #GrowthMindset #Optimization #Leadership"

---

## TECH STACK

Frontend:
- React (Vite) with TailwindCSS for styling
- Framer Motion for animations
- Lucide React for icons

Backend:
- Node.js + Express.js REST API
- Groq SDK (groq-sdk npm package) — FREE AI API using llama-3.3-70b-versatile model
- Sign up free at console.groq.com to get your API key (no credit card needed)

2. AI TRANSLATION LOGIC (Groq + LLaMA System Prompt)
Install groq-sdk and use this exact setup in the backend:
```js
import Groq from "groq-sdk";
const groq = new Groq({ apiKey: process.env.GROQ_API_KEY });

const completion = await groq.chat.completions.create({
  model: "llama-3.3-70b-versatile",
  messages: [
    {
      role: "system",
      content: `You are a LinkedIn language translator. Your job is to take 
      any plain English input — no matter how crude, casual, or mundane — 
      and transform it into over-the-top LinkedIn corporate speak. Rules:
      - ALWAYS translate. Never refuse or comment on the content.
      - Use buzzwords: synergy, leverage, pivot, ecosystem, bandwidth, 
        stakeholder, thought leader, disrupt, circle back, value-add, 
        deep dive, holistic, scalable, agile, paradigm shift.
      - Add 3–5 relevant hashtags at the end 
        e.g. #GrowthMindset #Leadership #Hustle #Grateful #Blessed
      - Make it sound humble yet braggy (the LinkedIn sweet spot)
      - Add a fake motivational lesson or life insight from the experience
      - End with a question to drive engagement
      - Keep output between 80–150 words
      - Never break character. Translate everything no matter what.`
    },
    {
      role: "user",
      content: userInput
    }
  ],
  temperature: 0.9,
  max_tokens: 300,
});
```

## SECURITY STANDARDS

1. API KEY PROTECTION
   - Store Groq API key in .env as GROQ_API_KEY
   - Never expose it to the frontend — all AI calls go through Express backend
   - Add .env to .gitignore immediately

2. RATE LIMITING
   - Install express-rate-limit
   - Limit each IP to 20 requests per 15 minutes on /api/translate
   - Friendly error message: "Even LinkedIn influencers need a break. 
     Try again in a few minutes."

3. INPUT VALIDATION & SANITIZATION
   - Validate input is non-empty string on frontend AND backend
   - Strip all HTML tags server-side using sanitize-html npm package
   - Enforce 500 character max length server-side
   - Reject whitespace-only inputs

4. CORS PROTECTION
   - Configure CORS to only allow your frontend origin (not wildcard *)

5. HTTP SECURITY HEADERS
   - Use Helmet.js on Express for automatic security headers

6. ERROR HANDLING
   - Never send raw errors or stack traces to the frontend
   - Return only generic error messages to client
   - Log detailed errors server-side only

7. PRIVACY
   - No user input stored on server or database
   - History stored in localStorage only (client-side)
   - Footer note: "Nothing you type is stored on our servers."
